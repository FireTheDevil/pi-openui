# Versioning

This project is experimental. As described in [Semantic Versioning](https://semver.org/#spec-item-4), `0.x` versions do not promise a stable public API.

For future releases after `0.7.0`, this project uses the following convention:

- **Patch** (`0.7.0` → `0.7.1`): backward-compatible fixes and documentation or guidance updates, with no intentional breaking changes.
- **Minor** (`0.7.0` → `0.8.0`): new features or intentional breaking changes. Release notes must identify breaking changes and explain how to migrate.
- **1.0.0**: a commitment to a stable public API and Semantic Versioning's compatibility rules, not a claim that the software is bug-free.

Minor versions can continue through `0.10.0`, `0.11.0`, and beyond; `0.9.0` does not require a move to `1.0.0`. Earlier versions did not consistently follow this convention.
